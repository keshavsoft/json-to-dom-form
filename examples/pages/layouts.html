Layout variants

Vertical, horizontal, inline, and grid flavor

These examples show the same metadata model rendered in different presentation styles. The form data stays the same, while the arrangement and density of the UI changes to match the task.

1. Stacked form

Best for clean entry screens where each field deserves its own row and the user reads top to bottom.

Use it for Edit flows Detailed data entry
layout: "stacked"
body: { columns: ["itemName", "batchName", "amount"] }

2. Horizontal form

Useful when the labels are short and the field values need to be scanned quickly in a single line.

Use it for Filters Compact review
layout: "horizontal"
body: { columns: ["stockItem", "voucherNo", "unitPrice"] }

3. Inline quick filter

A glanceable arrangement for search and narrow operations, especially when multiple inputs belong together.

Use it for Search bars Date ranges
layout: "inline"
body: { columns: ["searchText", "dateFrom", "dateTo"] }

4. Grid / two-column form

Best for balanced forms where related fields sit side by side without losing readability.

Use it for Profile screens Master forms
layout: "grid-2col"
body: { columns: ["firstName", "lastName", "company", "email"] }
