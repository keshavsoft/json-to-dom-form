Project overview

Metadata-driven forms, made simple.

This project turns a column schema and a config object into a DOM form. It is intentionally narrow: it builds forms from data, not from a large application runtime.

What it does

  • Defines columns as metadata like key, label, and type.
  • Renders those columns into a DOM form based on config.
  • Supports layout and theme switching through config or runtime methods.
  • Produces a controlsTree for programmatic access and binding.
  • Lets you preload data and read it back later from the rendered form.

Typical use cases

  • Search and filter panels
  • CRUD-like data entry forms
  • Metadata-driven admin screens
  • Simple UI screens driven by field definitions

What it is not

  • A full form validation framework
  • A backend or data service layer
  • A general-purpose UI framework
  • A replacement for app-specific business logic
