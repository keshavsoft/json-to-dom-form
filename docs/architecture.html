Architecture

A compact rendering pipeline.

Core components

  • Form — public class that manages config, data, layout, and theme.
  • FormStore — stores columns and form data and resolves active columns.
  • buildForm — builds a spec tree from columns and config.
  • renderForm — converts the spec into concrete DOM and mounts it.
  • controlsTree — pruned rendered tree for binding or inspection.

Design intent

The architecture favors a small public surface, config-first rendering, and predictable behavior. It keeps the runtime lean instead of turning into a heavy framework.

Version split

The repo contains versioned folders from v1 to v4. They show how the library evolved, while the latest export remains the active contract for the project.
