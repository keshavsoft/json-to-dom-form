How it works

The form pipeline is simple.

Flow

Form
  -> FormStore
  -> buildSpec / buildForm
  -> renderForm
  -> DOM nodes
  -> controlsTree

1. Define columns

Each field is described with metadata like key, label, and type.

2. Define config

Config decides active fields, layout, theme, and section structure.

3. Render form

The form instance builds a spec, generates DOM, and mounts it into a target container.

4. Read data back

Once rendered, the form can be updated, reset, or queried with getData(). This keeps the project practical without adding a large runtime layer.
